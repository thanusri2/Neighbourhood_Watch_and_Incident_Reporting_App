---

**1.0**

---

## Description

Community Sentinel is a web-based Neighborhood Watch and Incident Reporting System developed to improve security management in residential communities. The application provides a centralized platform where residents can report security incidents, security guards can investigate assigned cases, and community administrators can monitor and manage all incidents efficiently.

This document defines the initial software requirements for the project. It serves as a foundation for the design, development, testing, and maintenance of the application.

---

## Technology Stack

- **Frontend:** React.js
